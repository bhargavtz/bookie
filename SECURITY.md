# Security Policy

## Supported versions

Bookie is a small portfolio frontend. Security fixes are considered for the default branch; older snapshots are not actively supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the maintainer privately through the email address listed on the maintainer's GitHub profile: [@Bhargavtz](https://github.com/Bhargavtz).

Include:

- A concise description of the issue and its potential impact
- Reproduction steps or a minimal proof of concept
- The affected commit, route, or dependency if known
- Any suggested mitigation

Please allow reasonable time for assessment and remediation before public disclosure. Do not include real credentials or personal data in a report.

## Scope notes

The current repository is a client-side presentation project. It does not provide an authenticated backend or a production newsletter service. Do not treat the demo form as a secure data-collection system.
