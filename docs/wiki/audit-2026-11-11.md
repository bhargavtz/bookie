## 5. Code findings (2026-11-11, `c6e855b`)

Architecture and correctness:
- `src/app/page.tsx` is a client component (`"use client"`), so the whole page is a client bundle; `Footer.tsx` is also `"use client"` with no need.
- Navbar adds a `scrolled` class (page.tsx) with no matching CSS rule in `globals.css`.
- Body font `Poppins` (globals.css) is never loaded; the Geist variables from `layout.tsx` are unused.
- Tailwind is installed and in PostCSS but `globals.css` has no Tailwind import; zero utilities are generated.
- GSAP: each component registers ScrollTrigger and animates via global class selectors with no `gsap.context` and no cleanup; `scrub` and `toggleActions` are combined; no `prefers-reduced-motion` handling.
- Newsletter form: `console.log` plus `alert("Thank you for subscribing!")`; no backend, so the thank-you message is untrue; uses `suppressHydrationWarning` workarounds.
- Content claims are invented: "10K+ books, 50K+ readers, 1M+ downloads", "Fiction 5,000+ Books", etc. Footer states 2024 and a placeholder email `hello@bookie.com`.

Accessibility (to verify with axe in S7):
- Logo is an `<h1>`; there is no `<main>` landmark or skip link; emoji used as icons without labels; no `:focus-visible` styling; nav links hidden at <=768px with no mobile menu; anchor links implemented with JS `scrollIntoView`; white text on `#6366f1` is about 4.47:1 and on `#818cf8` about 3:1.

Images: `next/image` used with fixed 200x300 attributes while CSS forces 100% x 200px; source files up to 5626x3750 px and 1.7 MB.

## 7. Reference site notes (2026-11-11; functional ideas only)

Fetched `https://codingpdf.freeforall.dev/`, `/categories`, `/topic/algorithms` for UX flows. No assets, text, covers or URLs are reused.

- Flow: home with search box, topic tiles with counts, featured strip; topics index (15 topics, books may sit in several); paginated topic listing (12 per page, "showing x-y of z", breadcrumbs, topic sidebar, search box); book page combining reading and download; collection-by-source-folder listing; footer links to privacy, terms, contact.
- No visible filters or sorts, no visible licence or takedown statement, and many titles appear to be well-known commercial books offered as free (observed 2026-11-11). The site cannot serve as evidence that such content is allowed. Bookie must default to unpublished and require rights evidence ([decision-rights-enforcement](decision-rights-enforcement.md)).
- Ideas worth taking: topic counts, card-level "open" action, breadcrumbs, per-topic search, pagination summary, no-account reading. Ideas to add: filters (technology, level, language, year), sort, bookmarks/progress, licence badge on each book.
