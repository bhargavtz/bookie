# Assets and provenance

Last updated: 2026-11-12 (S7b documentation pass; working tree on top of `c6e855b`). Originally written by S3a on 2026-11-11.

Rule: a file ships in `public/` only with a provenance record here. Book covers are never images from third parties: they are generated in CSS by `BookCover3D` from the title and author supplied as props. Admins may upload a cover for a book; that file lives in storage, not in `public/`, and its rights are the uploader's responsibility (open question in [open-questions.md](open-questions.md)).

## Shipped in `public/` (verified 2026-11-12)

No raster or icon art. The only entry is `public/pdfjs/`, which is generated by `npm run assets:pdfjs` from the pinned `pdfjs-dist` package (worker, CMaps, standard fonts, ICC profiles, wasm) and is gitignored. It is third-party code under its own licence (Apache-2.0 per the upstream project; confirm against `node_modules/pdfjs-dist/package.json` before redistributing) and is not art. `src/app/favicon.ico` is a legacy file of unknown origin (the audit noted this, 2026-11-11); replacing it is an open question.
